# Sentra

Учебное веб-приложение на Python для обнаружения фишинговых ссылок и вредоносных Windows PE-файлов с помощью машинного обучения.

Для запуска выполните команду из корня репозитория.

```sh
docker compose -f sentra/compose.yaml up --build -d
```

После запуска откройте [локальный сканер](http://127.0.0.1:8765/). Архитектура, REST API, данные для обучения и результаты сравнения моделей описаны в [документации проекта](sentra/README.md).
